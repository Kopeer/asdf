Vercel 1분 배포 가이드

  1. 상단의 [배포용 ZIP 전체 다운로드] 버튼을 눌러 프로젝트 파일들을 다운로드합니다.
  2. GitHub에 새로운 레포지토리를 만들고 압축 해제한 파일들을 푸시합니다.
  3. Vercel.com에서 GitHub 저장소를 Import합니다.
  4. [Environment Variables] 설정에 GEMINI_API_KEY를 등록합니다.
  5. [Deploy]를 눌러 완벽하게 서버리스 기반 웹앱을 배포합니다!
